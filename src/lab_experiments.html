🧪 Comparable Training Runs

Each run trains a fresh network from scratch (own replay buffer) for a training-time budget and is evaluated every few iterations with a fixed protocol: the same AlphaZero simulations, openings and opponents for every run. So the curves answer "how strong does this setup get per minute of training / per self-play game?". Training time counts self-play + SGD only, never evaluation. Runs execute one at a time and only while live training is paused; live training waits until the current run ends (stop it in the table to train live sooner). For fair timing, avoid running arena matches meanwhile. Results are saved to lab_experiments.json.
